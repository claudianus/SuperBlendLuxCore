# 2.11.13 확장 호환성 검증

Bump Distance와 Strength를 분리하고 새 엔진의 `bumpnormal` 법선 혼합을 사용한다. 참조 오브젝트의 역행렬과 Camera/Window의 카메라·투영 행렬로 월드 히트 위치를 변환한다. 원근과 직교, 시프트와 종횡비를 포함한다. 파노라마 좌표와 움직이는 공간 및 뷰포트의 다른 카메라는 이번 완료 범위에 포함하지 않는다.

`dev-tools/cycles-coordinate-render-regression.py`는 Cycles와 실제 CPU/GPU 렌더 EXR을 비교한다. 물리적으로 제한되는 음수 발광을 피하도록 좌표를 양수 색으로 옮긴다. 1280×720 Metal 검사의 Camera, 원근 Window, 직교 Window, 참조 Object 평균 절대 오차는 각각 0.00000365, 0.00000200, 0.00000210, 0.00000148이었다. 노이즈 제거·클램프·스펙트럼 변환을 끈 RGB 기준이다.

설명서의 한국어 홈페이지와 10개 한국어 장을 추가하고 모든 영문 장에 대응 언어 링크를 연결했다. 전체 호환성 보장 문구를 지원 범위와 제한 설명으로 정정했다. 소스 검증과 공개 배포 ZIP 검증은 구별한다.

192×108 CPU 좌표 4조건도 평균 절대 오차 0.00000594~0.00001541로 통과했다. 새 엔진은 음수 Strength 제한과 1 초과 Strength의 외삽까지 CPU·Metal 12조건으로 검증했다.
