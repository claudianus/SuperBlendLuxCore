# 2.11.13 확장 호환성 검증

Bump Distance와 Strength를 분리하고 새 엔진의 `bumpnormal` 법선 혼합을 사용한다. 참조 오브젝트의 역행렬과 Camera/Window의 카메라·투영 행렬로 월드 히트 위치를 변환한다. 원근과 직교, 시프트와 종횡비를 포함한다. 파노라마 좌표와 움직이는 공간 및 뷰포트의 다른 카메라는 이번 완료 범위에 포함하지 않는다.

`dev-tools/cycles-coordinate-render-regression.py`는 Cycles와 실제 CPU/GPU 렌더 EXR을 비교한다. 물리적으로 제한되는 음수 발광을 피하도록 좌표를 양수 색으로 옮긴다. 1280×720 Metal 검사의 Camera, 원근 Window, 직교 Window, 참조 Object 평균 절대 오차는 각각 0.00000365, 0.00000200, 0.00000210, 0.00000148이었다. 노이즈 제거·클램프·스펙트럼 변환을 끈 RGB 기준이다.

설명서의 한국어 홈페이지와 10개 한국어 장을 추가하고 모든 영문 장에 대응 언어 링크를 연결했다. 전체 호환성 보장 문구를 지원 범위와 제한 설명으로 정정했다. 소스 검증과 공개 배포 ZIP 검증은 구별한다.

192×108 CPU 좌표 4조건도 평균 절대 오차 0.00000594~0.00001541로 통과했다. 새 엔진은 음수 Strength 제한과 1 초과 Strength의 외삽까지 CPU·Metal 12조건으로 검증했다.

추가 점검에서 Vector Math Reflect의 비단위 법선 정규화, Refract의 전반사, Wrap의 영폭, Round의 음수 경계, Mix의 비균일 벡터 계수 및 계수 클램프/외삽을 수정했다. Blender 5.2의 Factor 소켓 세부 유형도 함께 처리한다. `dev-tools/cycles-vector-render-regression.py`가 20개 조건을 실제 영상으로 비교한다. 감싸기·반올림 불연속 경계는 샘플 위치 차이 때문에 전체 평균과 95백분위 기준을 사용하고, 연속 함수는 99백분위를 검사한다. 전체 평균 오차 제한은 0.0002다.

추가 벡터·Mix 20조건은 CPU와 Metal에서 모두 통과했다. 공통 텍스처 참조를 수정한 최종 엔진으로 E23 재질·조명·볼륨 코퍼스는 CPU 90/90, Metal 90/90을 통과했다. 이 코퍼스는 128×128의 넓은 허용 오차를 포함하므로 제작 장면의 시각적 동등함이나 99% 기능 지원의 근거로 삼지 않는다. 네이티브 수학·Snap 54조건, 픽셀 필터 12조건, 카메라 매질 8조건과 변환된 표면의 범프 미분 6조건도 통과했다.

`dev-tools/cycles-production-corpus.py`는 별도로 준비된 외부 Cycles 장면을 읽어 1280×720 RGB 기준 EXR·PNG·측정 JSON을 저장한다. 노이즈 제거와 밝기 클램프를 끄고 같은 샘플 수를 사용한다. 이미지의 차이를 숨기기 위한 정규화나 자동 통과 판정은 하지 않는다. 측정 수치는 실측 산출물을 확인한 뒤 배포 검증 기록에 추가한다.
