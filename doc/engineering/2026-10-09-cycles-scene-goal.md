# 기존 Cycles 씬의 무변환 렌더 목표

2026-10-09 사용자가 정의한 목표를 기준으로 진행한다. 기존 Cycles 노드·설정 기반 씬을 수정하거나 수동 변환하지 않고 SuperLuxCore로 바로 렌더할 수 있어야 한다. 시각적·논리적 의미를 보존하고 SuperLuxCore의 고품질 기본값을 유지한다. 비트·픽셀·난수 패턴의 동일함은 요구하지 않는다. 호환 기능은 사용자 편의를 위한 것이며 엔진의 주목적이나 품질 기준을 Cycles 복제에 맞춰 바꾸지 않는다. 사용자 OSL·베이킹은 기존에 유보한 별도 범위다.

## 합격 기준

- 올바른 소켓·설정·좌표를 읽고 연결된 입력을 빠뜨리지 않는다.
- Factor=0의 원색, Ramp Alpha, 곡선 채널, 흡수·산란·발광, 모션 제외 등 제작 의도를 보존한다.
- 확장 전용 설정은 명시적으로 작성했을 때 우선하며, 원본 Blender 데이터의 자동 해석은 씬을 수정하지 않는다.
- 기본 스펙트럼과 물리 품질을 유지한다. 자동으로 RGB로 바꾸거나 클램프·Filter Glossy를 가져와 품질을 낮추지 않는다.
- CPU·Metal의 실제 720p 이상 렌더와 이미지 검토를 포함한다. 순수 색·좌표 연산은 좁은 수치 기준으로 검사할 수 있지만 물리 모델·수렴·난수는 시각적 의미와 유효성으로 판정한다.
- 제작 장면, 패스·컴포지터, 변위·법선·이미지·인스턴스·시간 조합의 검증이 남은 상태를 전체 완료로 세지 않는다.

## 첫 수정 묶음

첫 묶음 당시의 수정 기록이다. 후속 차원·이미지 구현과 검증은 아래 항목에서 구분한다.

Magic의 실제 깊이 RNA는 `turbulence_depth`다. Scale·Distortion·Vector를 산술 텍스처로 전달한다. Noise 1D는 없는 Vector 소켓을 조회하지 않고 W를 보존한다. White Noise 1D도 W 씨앗을 읽으며 기존 3D의 기본 Vector를 위치로 바꾸지 않는다. Voronoi 1D는 예외를 막았지만 아직 대체값이므로 미완료다.

Map Range는 활성 스칼라·벡터 소켓, 네 가지 보간, 역방향 범위와 외삽·클램프를 처리한다. Layer Weight는 Blend·Normal 연결, 앞뒷면 Fresnel과 Facing의 구간별 지수를 반영한다. HSV Factor와 Gamma를 일반 색 입력에서도 처리한다. Ramp는 별도 Alpha와 Blender 색 공간·보간 평가를 사용한다. Float·Vector·RGB Curve의 채널과 Factor·외삽을 보존한다. 곡선 표는 GPU 16항목 한도를 지키면서 분할하며 표 압축의 채널별 최대 오차는 1e-4로 제한한다.

RGB 혼합은 채널별 연산, HSV 기반 모드, Factor 클램프·외삽과 결과 클램프를 분리한다. Vector SIGN·POWER는 채널별로 계산한다. RGB 결과의 `makefloat3.color`는 스펙트럼 변환과 좌표 데이터를 구분해 전달한다.

그룹의 표시 이름 대신 소켓 식별자를 조회한다. 값 .8인 두 번째 중복 출력이 첫 값 .1로 바뀌던 오류를 고쳤다. 볼륨 합성은 비연결 입력 위치와 Factor를 유지하고 산란을 `clear`에 넣어 버리지 않는다. 위상 비대칭은 산란 계수로 가중한 단일 위상의 근사다. 흑체 발광은 온도·강도·Tint와 Cycles의 단위 휘도 색 계약을 전달한다. 엔진의 물리 스펙트럼은 유지한다. VDB 속성과 볼륨의 최종 수렴·방사량 검증은 남았다.

표준 투명 필름·모션·셔터·물체별 모션 제외는 가져오기 버튼 없이 읽는다. 명시적 확장 설정은 우선한다. 명시적으로 작성된 Cycles total/diffuse/glossy/volume 바운스 제한도 자동으로 읽는다. 설정 가져오기 연산자의 올바른 RNA 경로와 0바운스도 고쳤다. 투명·투과·완전 반사 깊이의 독립 계약은 엔진 작업이 남았다.

## 현재 범위와 다음 작업

목표 작업은 계속 진행한다. 이번 묶음을 전체 씬 호환 완료로 세지 않는다. 엔진 배포 바이너리는 2.11.13이며 검증 확장은 임시 프로필의 현재 소스다. main의 엔진·확장 버전은 2.11.14로 맞췄으며 새 wheel·패키지 빌드를 진행한다. 아직 새 버전의 정식 설치 검증·배포 완료를 뜻하지 않는다.

1. 로브별 조명·색·모션·Cryptomatte 등 남은 패스 계약을 완성한다.
2. 변위·법선·임의 이미지 좌표·애니메이션·UDIM 소비 경로를 검증하고 고친다.
3. 조명·월드·카메라·시간·인스턴스와 제작 씬을 검증한다.
4. 설치 가능한 2.11.14 패키지 검증과 정식 배포를 완료한다.

기준 목록은 [잔여 호환성 검수](2026-10-09-remaining-compatibility-audit.md)다. 이 목록의 픽셀 차이 항목은 새 사용자 목표의 의미 기준으로 다시 판정한다.

## 첫 묶음의 현재 소스 검증

검증은 Blender 5.2.1 LTS `9e2066aef7ef7e20c142ad7bd3303138a4304c93`, 엔진 2.11.13과 수정된 확장 소스의 격리 프로필에서 진행했다. 정식 설치 프로필의 이전 확장과 혼동하지 않는다.

- 변환 전수 검수 1,023조건에서 예외 0, 경고 조건 299다. 이전 배포본은 예외 38, 경고 조건 407이었다. Voronoi 1D의 중립 대체를 포함하므로 예외 0이 의미 호환 완료를 뜻하지 않는다.
- CPU·Metal 각각 720p의 고유 노드 조건 48개를 렌더하고 모든 비교 이미지를 직접 확인했다. 순수 색·좌표 연산 47조건의 CPU 최대 MAE는 0.000389이며 Metal도 0.002 미만이다. White Noise 3D는 엔진의 결정적 해시가 달라 색이 다르며 픽셀 일치의 합격 기준으로 세지 않는다. 4D W 누락은 여전히 결함이다.
- 실제 `path.spectral.enable=1`인 기본 스펙트럼 경로에서도 Gamma·Screen·RGB Curve 3조건을 CPU·Metal로 재검증했다. 16샘플 색 비교의 MAE는 0.014~0.019이며 이미지는 같은 색 연산의 의미를 보인다. 노이즈와 스펙트럼 변환 차이를 RGB 경로의 수치 기준과 혼동하지 않는다.
- 설정 가져오기 없이 720p·32샘플의 정지·모션·개별 물체 모션 제외 3조건을 양쪽 장치에서 검사했다. Cycles와 SuperLuxCore의 모션 폭은 각각 985와 989~990픽셀이며 제외된 물체는 정지 폭 280~282픽셀을 유지한다. 투명 모서리 알파는 0이고 원본 설정을 수정하지 않았다.
- 기본 스펙트럼의 흑체 발광과 흡수+산란 볼륨 각 2조건을 CPU·Metal에서 렌더했다. 유한 출력, 발광 복원, 산란의 색·형태·광원 반응을 확인했다. SuperLuxCore 산란 영상은 더 밝고 두 엔진의 32샘플 수렴도 다르다. 이 차이는 고샘플·방사량 검증 전에 완료로 판정하지 않는다.
- 기존 E37 어댑터 스냅샷 22/22개와 E23 제작 조합 회귀 90/90 검사가 통과했다. E23의 낮은 해상도는 기능 회귀 확인이며 720p 이미지 검증을 대신하지 않는다.

원본 EXR·PNG·수치·로그와 검토용 비교표는 상위 작업 폴더의 `test-scenes/validation-2026-10-09/cycles-scene-goal-phase1/`에 보존했다. `summary.json`은 음수 방출을 검사하던 초기 fixture를 양수 데이터 가시화로 바로잡은 최종 결과를 합친 48조건이다. `node-comparison-1.png`부터 `node-comparison-6.png`, `workflow-comparison.png`, `volume-comparison.png`, `spectral-comparison.png`를 모두 직접 검토했다. 모션과 볼륨의 적은 샘플 노이즈를 최종 품질 완료로 해석하지 않는다.

## 데이터 패스 묶음의 검증

Depth·Normal·Position·UV·IndexOB·IndexMA·Emit·Mist를 Blender의 원래 RenderResult 이름과 컴포지터 소켓으로 전달한다. 확장 AOV 패널을 별도로 켤 필요가 없다. Depth는 엔진 광선 거리의 정규화 값을 복사하지 않고 월드 위치에서 카메라 Z 깊이를 계산한다. Mist는 별도의 카메라 거리와 World의 start/depth/falloff를 사용한다. UV=0도 유효하므로 마스크는 교차 여부로 계산한다. 엔진 ID는 보존하면서 원래 Blender 물체·재질 `pass_index`에 대응시킨다.

Blender 5.2.1에서 720p·16샘플, CPU·Metal 원근 카메라 및 CPU 직교 카메라의 각 8패스를 검증했다. 원래 Cycles Render Layers 컴포지터를 만든 뒤 Normal 연결을 그대로 유지하고 엔진만 교체하여 최종 컴포지터 렌더를 확인했다. 내부 픽셀의 최대 평균 차이는 Position 0.00124 미만, Depth 0.00092 미만이며 인덱스 7·13은 정확하게 유지한다. 알파·경계 필터 차이는 내부 픽셀 비교와 구분한다. 직교 카메라의 Cycles·SuperLuxCore Normal PNG를 직접 검토했고 형태·방향·색 의미를 확인했다.

원본 EXR·실제 RenderPass의 NumPy 데이터·수치·로그는 `test-scenes/validation-2026-10-09/cycles-scene-goal-phase2/`에 보존했다. 검증 장면은 불투명 정적 표면이다. 시간에 따라 움직이는 카메라의 픽셀별 깊이, 투명 표면이 여러 겹인 Mist, Geometry Nodes 내부 점 인스턴스의 별도 ID는 추가 검증이 필요하다.

Diffuse/Glossy/Transmission Color를 모두 ALBEDO로 대체하던 매핑은 제거했다. 로브별 색, 광원 패스의 색 분리, 모션 벡터, Cryptomatte 메타데이터 등은 엔진/전달 계약의 추가 작업이 남아 있으며 명시적으로 경고한다. 이 묶음은 전체 컴포지터 호환 완료를 뜻하지 않는다.

데이터 패스 변경 후 E37 어댑터 스냅샷을 다시 실행해 22/22 검사가 통과했다.

## 월드 카메라 가시성 묶음

720p 실렌더에서 카메라 가시성을 끈 Cycles 월드는 검은 배경·알파 1이며, 투명 필름은 검은 배경·알파 0이라는 별도 계약을 확인했다. 이전 변환은 월드 숨김을 AOV의 투명 필름으로만 처리하고 최종 RGB에 전달하지 않아 월드가 계속 보였다.

월드 광원의 `cameragain=0`으로 카메라 발광만 숨긴다. 간접 조명은 유지하며 원본 필름 알파를 바꾸지 않는다. Light Path 기반 카메라 게인이 있어도 월드의 카메라 제외를 우선한다. CPU·Metal의 720p·32샘플에서 표시·숨김·투명 3조건을 검사했고, 두 엔진 모두 RGB·알파 계약과 구체의 조명 유지가 통과했다. 세 조건의 비교 이미지를 직접 확인했다. 원본 EXR·PNG·수치·로그는 `test-scenes/validation-2026-10-09/cycles-scene-goal-phase5/`다.


## 차원별 White Noise·Voronoi 묶음

White Noise의 1~4차원×Value/Color×W 두 값 16조건과 기존 3D 하나를 CPU·Metal의 720p로 검증했다. 최대 평균 차이는 CPU 1.11e-7, Metal 3.02e-7 미만이다. W 변화는 1D·4D에서만 결과를 바꾸고 2D·3D에서는 1e-5 허용치 내에서 유지한다. 기본 스펙트럼의 3D 추가 검사도 유한하고 같은 색을 유지한다. 기존 3D의 해시 차이와 4D W 누락을 해소했다. 증거와 직접 검토한 전체 비교표는 `cycles-scene-goal-phase3/`다.

Voronoi는 F1/F2/Smooth F1/Distance to Edge/N-Sphere Radius, 네 차원, 네 거리 방식과 Distance/Color/Position/W/Radius를 연결된 입력으로 읽는다. 기존 엔진 자체 난수의 초기 검증과 최종 Blender 5.2 PCG 셀 패턴 검증은 분리했다. 최종 CPU·Metal 각각 41조건의 최대 평균 차이는 0.000809 미만이다. 실제 셀의 형태·경계·색·위치 비교 이미지를 직접 검토했다. 4D 거리 동률 조건은 수치 일치 합격으로 세지 않았고 비동률 W 조건을 별도로 통과했다. 극단 좌표·0 Minkowski 지수·모든 최대 프랙탈 조합까지 전수 통과한 뜻은 아니다.

벡터가 색 입력으로 연결될 때만 RGB 채널을 한 번 스펙트럼으로 변환한다. 좌표를 스펙트럼 값으로 취급해 Vector Curve/Vector Map Range/Position의 색이 바뀌는 경로를 고쳤다. 기본 스펙트럼 CPU·Metal의 Vector Curve·Vector Map Range·Voronoi 셀 3출력 총 5조건도 720p로 확인했다. 최대 평균 차이는 CPU 0.02923, Metal 0.03005 미만이며 16샘플의 스펙트럼 노이즈와 RGB 수치 기준을 구분한다. 비교표를 직접 검토했고 셀 배치와 색·벡터 의미를 확인했다. 증거는 `cycles-scene-goal-phase4/`의 `*-pcg`, `*-pcg-spectral`, `pcg-summary.json`과 두 최종 비교 이미지다.

## 이미지 입력·알파·색 공간 묶음

Blender의 OCIO 파일과 이미지 색 공간을 그대로 읽어 선형 작업 공간으로 변환한다. sRGB의 감마 2.2 근사와 나머지 공간의 무변환을 제거했다. Non-Color와 별도 Alpha는 데이터로 읽는다. 축소 `.tx` 캐시가 RGB에 알파를 곱해 Non-Color 값까지 줄이던 결함을 고쳤고, 이전 잘못된 캐시는 새 `.slc-raw-v1.tx`와 구분한다.

이미지의 알파 모드와 실제 최종 출력으로 연결된 Alpha를 읽는다. None의 Alpha는 1, 별도 Alpha는 원래 값을 유지한다. 그룹의 사용되지 않는 Alpha와 죽은 노드 연결이 Color를 바꾸지 않도록 최종 경로를 추적한다. 원본 씬·노드·이미지 설정은 수정하지 않는다.

CPU·Metal 각각 720p·16샘플의 RGB 21조건과 기본 스펙트럼 6조건을 검증했다. 여섯 입력 공간, 표면·월드, 알파 연결/비연결, Premultiplied/None/Channel Packed, 그룹과 죽은 Alpha 분기를 포함한다. RGB 최대 평균 차이는 0.002072 미만, 기본 스펙트럼은 CPU 0.002672와 Metal 0.002545 미만이다. 모든 RGB 비교표 5장과 스펙트럼 비교표를 직접 검토했다. 증거는 `cycles-scene-goal-phase6/`다. 알파가 공간적으로 달라지는 경계 필터·시간·UDIM·생성 이미지·임의 OCIO 구성 전체를 검증한 뜻은 아니다.

최종 노드 소스로 전수 변환을 다시 실행해 1,023조건의 예외 0, 경고 조건 257을 확인했다. 초기 배포본의 38/407과 비교해 개선되었지만 경고·지원 대체·미검증 제작 조합이 남아 있다. E37의 22/22 회귀도 통과했다. 전체 의미 호환 완료나 99%의 분모로 사용하지 않는다.


## 원본 UV·스칼라 변위 모드 묶음

2.11.14 Release 엔진·확장으로 BUMP/DISPLACEMENT/BOTH의 상수·UV 기울기 6조건을 CPU·Metal의 720p 기본 스펙트럼에서 검사했다. BUMP에서 실제 메시가 움직이던 결함, 연결 Midlevel/Scale 누락, BOTH에서 변위된 법선에 범프 기울기를 중복 적용하는 경로를 고쳤다. Cycles와의 중앙 표면 법선 최대 평균 차이는 CPU 0.000066, Metal 0.000072 미만이고 깊이는 0.000860 미만이다. BUMP 깊이는 4를 유지하며 실제 변위의 상수 깊이는 약 3.88이다. 원래 Cycles Normal/Depth 패스와 컴포지터를 유지한 엔진 전환으로 검사했다.

UV 좌표를 반복 무늬처럼 해석하여 경계의 1을 0으로 되돌리던 엔진 경로를 원본 좌표 출력과 구분했다. Texture Coordinate·UV Map의 정수 타일·음수·UV=1 경계 6조건도 CPU·Metal 720p RGB 진단으로 검사했다. 최대 평균 차이는 양쪽 모두 0.000083 미만이다. 원본 EXR·NumPy 패스·PNG·로그·수치는 `test-scenes/validation-2026-10-09/cycles-scene-goal-phase7/`에 보관했고 두 비교표를 직접 검토했다.

이 묶음의 C28은 부분 해결이다. World 공간·연결 Normal·적응 세분화와 BOTH의 변위 전 3D 좌표 복원이 남아 있다. 벡터 변위, 인스턴스 UV와 임의 텍스처 Vector 소비 경로의 완료를 뜻하지 않는다.
