문제 해결

렌더가 끝나지 않을 때

샘플/시간/노이즈 종료 조건이 켜져 있는지 확인합니다. 첫 GPU 렌더는 커널 준비 시간이 필요합니다. 콘솔의 컴파일 진행과 실제 샘플 증가를 구별하십시오.

GPU가 보이지 않을 때

장치 목록과 실제 렌더 로그를 확인합니다. Apple silicon에서는 Metal GPU를 선택합니다. 플랫폼에 맞는 ZIP과 Blender/Python 버전을 맞추십시오.

장면이 너무 밝거나 어두울 때

색 관리, 스펙트럼 모드, 클램프, 필터, 볼륨 깊이와 카메라의 시작 매질을 확인하십시오. 볼륨 경계와 불투명 표면을 정확히 같은 위치에 놓으면 교차 순서 차이가 발생할 수 있습니다. 서로 조금 떨어뜨린 진단 장면으로 원인을 좁히십시오.

텍스처가 다를 때

Generated/Object/UV 공간과 참조 오브젝트, 카메라 유형과 시프트, Bump Distance/Strength를 확인합니다. 미지원 노드 경고와 연결된 입력 제한을 읽으십시오.
