설치

요구 사항

Blender 5.2 이상과 Python 3.13에 맞는 확장 ZIP을 사용합니다. macOS Apple silicon은 macos_arm64, Intel은 macos_x64, Windows는 windows_x64, Linux는 linux_x64를 선택합니다. Metal은 Apple silicon과 지원되는 macOS에서 사용합니다.

배포 패키지 설치

  1. GitHub 배포 목록에서 운영체제에 맞는 ZIP을 받습니다.
  2. Blender의 Edit → Preferences → Get Extensions 메뉴에서 Install from Disk를 선택합니다.
  3. ZIP을 설치하고 SuperLuxCore를 활성화합니다. 엔진 wheel이 포함되어 별도 pip 설치는 필요하지 않습니다.
  4. Render Engine을 SuperLuxCore로 바꾸고 첫 렌더를 수행합니다.

현재 정식 배포는 2.11.13이며 엔진과 확장 버전이 같습니다. 네 플랫폼 ZIP의 구성·해시·소스 커밋 산출물 증명을 검증했습니다. Apple silicon 최종 ZIP을 새 Blender 5.2.1 프로필에 오프라인 설치하고 빈 Metal 캐시에서 기본 스펙트럼 1280×720·32샘플 렌더를 48.25초에 완료했습니다. Mac ZIP SHA-256은 dccd7560eba995eb9b2790e2e09ae8408a25695d70a7d1fe087c6ee6462d2963입니다. Windows·Linux·Intel Mac의 실제 GPU 실행 검증은 남아 있습니다. 배포 검증 기록과 호환성 제한을 함께 확인하십시오. 확장과 엔진 버전이 다르면 먼저 같은 배포물로 다시 설치하십시오.

버전 확인

import pysuperluxcore
print(pysuperluxcore.Version())

첫 GPU 렌더는 커널 컴파일로 오래 걸릴 수 있습니다. 같은 장면의 두 번째 렌더와 구별하십시오. 새 버전 테스트는 기존 개발 설치가 섞이지 않은 별도 Blender 프로필에서 수행하는 것이 좋습니다.
