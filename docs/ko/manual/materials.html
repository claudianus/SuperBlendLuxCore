재질과 텍스처

Cycles 재질

Principled BSDF는 엔진의 OpenPBR 계열 재질로 변환됩니다. Base Color, Metallic, Roughness, IOR, Transmission, Coat, Subsurface 등 각 입력이 옮겨지지만 모든 셰이더의 수치적 동일함을 의미하지 않습니다. 유리, 금속, 확산, 발광, 머리카락은 장면별로 확인하십시오.

범프

2.11.13은 Bump의 Distance와 Strength를 분리합니다. 먼저 Distance로 표면 기울기를 만들고 원래 법선과 결과 법선을 Strength로 혼합합니다. Invert는 거리 부호에 적용합니다. 연결된 Distance/Normal과 실제 변위는 추가 제한이 있으므로 경고와 영상을 확인하십시오.

좌표

UV, Generated, Object, Normal과 Reflection을 지원합니다. 2.11.13에는 참조 오브젝트가 있는 Object 좌표와 원근·직교 카메라의 Camera/Window 좌표 변환이 추가되었습니다. 파노라마 Window, 카메라가 다른 뷰포트, 시간에 따라 움직이는 좌표 공간은 이 검증에 포함되지 않았습니다.

색과 스펙트럼

스펙트럼 렌더링과 RGB 비교는 별도의 기준입니다. 색 관리와 스펙트럼 변환 차이를 재질 오류와 혼동하지 마십시오. 음수 발광은 물리적 렌더 경로에서 제한되므로 좌표 검증용 색은 양수로 옮겨 비교합니다.
