첫 렌더

  1. 확장을 활성화하고 Render Engine을 SuperLuxCore로 선택합니다.
  2. 장면에 재질, 조명, 카메라가 있는지 확인합니다.
  3. CPU 또는 GPU 장치를 선택합니다. Apple silicon GPU는 Metal 장치로 표시됩니다.
  4. F12로 렌더를 시작합니다. 종료 조건에서 샘플 수나 목표 노이즈를 설정합니다.

Cycles 장면

Import Cycles Settings는 샘플, 경로 깊이, 노이즈 제거와 일부 필름 설정을 옮깁니다. 원본 파일의 사본을 사용하고 작은 비교 렌더를 먼저 수행하십시오. 지원되지 않는 노드 경고를 확인하십시오.

품질 기준

처음 비교할 때는 같은 해상도와 시점, 충분한 샘플 수를 사용합니다. 노이즈 제거, 클램프와 색 관리 차이를 별도로 확인하십시오. 품질을 맞춘다고 자동으로 간접광 클램프나 코스틱 억제를 적용하지 마십시오.
