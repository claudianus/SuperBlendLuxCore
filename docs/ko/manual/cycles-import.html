Cycles 장면 가져오기

설정 가져오기

Import Cycles Settings로 지원되는 샘플, 깊이, 노이즈 제거와 필름 설정을 가져옵니다. Box, Gaussian, Blackman–Harris 필터의 이름뿐 아니라 폭의 의미도 비교합니다. Filter Glossy와 간접광 클램프는 사용자가 선택한 설정을 기준으로 다룹니다.

2.11.13에서 수정한 차이

  • 범프 차분의 정밀도 보호를 광선 충돌 오차에서 분리했습니다.
  • Bump Strength의 법선 혼합을 CPU와 GPU에 구현했습니다.
  • 카메라 앞의 불투명 물체에 가려진 볼륨 경계까지 조사하여 시작 매질을 찾습니다.
  • 참조 오브젝트 좌표와 원근·직교 Camera/Window 좌표를 변환합니다.

검증

범프 합성 12개와 Beer–Lambert 카메라 흡수 8개 조건이 CPU와 Metal에서 통과했습니다. 1280×720 모래 장면의 Cycles 대비 평균 밝기는 가까운 영역 0.985배, 중간 영역 0.936배였습니다. 잔여 차이가 있으므로 모든 범프 장면의 동등함을 선언하지 않습니다.

제한

정확히 겹치는 볼륨 경계와 표면, 연결된 Bump 입력, 일부 절차적 노드, 변위, 복합 재질과 GPU 광선 연결 추정기는 추가 검증이 필요합니다. 베이킹과 사용자 OSL은 현재 작업의 완료 범위에 포함하지 않습니다. 경고를 숨기거나 미지원 기능을 완전 지원으로 취급하지 마십시오.
