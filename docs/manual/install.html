Installation

Requirements

ComponentMinimum
Blender5.2.x LTS (Python 3.13)
macOS14+ on Apple silicon (Metal GPU backend)
Windows / LinuxOpenCL-capable GPU or CPU

Install the release ZIP

  1. Download the latest superluxcore-addon-*.zip from the releases page. The ZIP bundles the engine wheel (pysuperluxcore) and the addon.
  2. In Blender: Edit → Preferences → Add-ons → Install from Disk → pick the ZIP.
  3. Enable Render: SuperLuxCore.
  4. Switch the active render engine to SuperLuxCore.

Verify

# Blender scripting console / Text Editor
import bpy
bpy.context.scene.render.engine = "SUPERLUXCORE"
print(bpy.context.scene.superluxcore.config.engine)

GPU backends

Metal is used automatically on Apple silicon (device type METAL_GPU). Vulkan requires a bundled toolchain — see Troubleshooting → Vulkan. CPU is always available and is the reference implementation.
