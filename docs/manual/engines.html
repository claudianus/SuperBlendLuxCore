How the addon maps them

The Blender UI exposes two lighting integrators - Pathtracing and Bidirectional - plus a Device selector and a Use Tiled Path toggle. The concrete engine is derived:

UI choiceEngine emitted
Pathtracing + CPU + tiled offPATHCPU
Pathtracing + GPU + tiled offPATHOCL
Pathtracing + tiled onTILEPATH* (CPU or OCL)
Pathtracing in the viewportRTPATH*
BidirectionalBIDIRCPU

FILESAVER is reached via the Use FileSaver option rather than the integrator enum.

GPU vs CPU

Pick Device in the render settings:

  • AUTO — GPU when one is enabled in addon preferences, else CPU.
  • CPU — all CPU threads (NATIVE_THREAD devices).
  • OCL — the GPU backend selected in addon preferences (OpenCL / CUDA / Metal). The identifier is kept for .blend compatibility.

Wavefront queues

pathocl.wavefront = on|off|auto controls the per-state task queue path. On Apple silicon the measured clean-GPU ratio is off ≈ 9.5 Ms/s vs on ≈ 3.9 Ms/s — auto resolves to off; keep it there unless a scene benchmark says otherwise.
