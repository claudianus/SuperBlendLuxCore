Denoising

OIDN 2.x

Intel Open Image Denoise is the default denoiser. On Apple silicon the device_metal OIDN backend runs on the GPU — ~3.8 ms at 512² vs ~66 ms on CPU (17×). The Metal device ships inside the release wheel; nothing extra to install.

Components mode

Denoise Emission plus the component-decomposed path denoise each radiance channel separately, preserving material boundaries. Enable it under Denoiser → Components.

Interactive tick

During a render the viewport refreshes the denoised frame roughly once per second (denoise_interactive, on by default). The worker computes OIDN off the UI thread; the main thread only uploads the finished image.

Halt criteria

Combine denoise with the adaptive-error halt (film.adaptiveerror.*) to stop on a statistical noise level instead of a fixed sample count — the Corona-style "just renders until it's clean" behaviour.
