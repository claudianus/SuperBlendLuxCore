Preset library

Material → Presets menu in the material editor inserts a ready-made node tree. The Physically Measured category builds each of the 17 measured spectral n/k metals (Aluminium through Zinc) as a Metal node wired to a Fresnel preset texture - the engine ships the measured curves, so the reflectance is physically accurate by construction (GGX + multibounce enabled). The eight measured carpaint stacks (2k Acrylack, BMW 339, Ford F8, Opel Titan, Polaris Silber, Blue, Blue Matte, White) expose the multi-layer flake paint model in one click.

Textures

Noise / Voronoi / Brick / Checker / Gradient / Magic / Wave / White Noise / Gabor / IES all map natively; feature subsets warn in the export log. Image textures support UV / Generated / Object coordinates and the Mapping node.
