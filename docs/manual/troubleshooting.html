Troubleshooting

Render never finishes

The adaptive-error halt is the intended stopping rule. If a scene looks done but the render keeps going, check:

  • halt.use_noise_level on, target 3%
  • Light-traced caustics are intentionally excluded from the pixel convergence test — they need use_light_samples or a time cap for a guaranteed stop.

GPU not used

  • Metal: requires a METAL_GPU device listed in Addon Preferences → Devices. Integrated Apple GPUs qualify.
  • On low-VRAM GPUs the engine drops to the out-of-core profile automatically.

Vulkan

The Vulkan backend needs a shader toolchain (clspv) in ~/.luxcore or on PATH. The released wheel bundles it for macOS (MoltenVK); on Linux/Windows install it manually or use the OpenCL/Metal backend.

Caustics look wrong / missing

  • Confirm Add Light Tracing is on (default).
  • On GPU, wavefront queues must be off (default); the queue path is a measured regression on Metal.
  • Check the denoiser is not hiding real caustic energy — denoiser.enabled toggles it.

Viewport lags during render

Runtime resolution reduction is enabled by default (SetRuntimeResolutionReduction); the preview downsamples so interaction stays responsive. Disable under Viewport → Runtime Resolution Reduction.
