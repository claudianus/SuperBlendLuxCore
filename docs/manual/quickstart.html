Quickstart

From zero to a finished render in under two minutes.

1. Pick the engine

Render Properties → Render Engine → SuperLuxCore. Leave Lighting integrator at PATH and Device at AUTO — the GPU is used when one is available.

2. Render

Press F12. No other setup is needed: adaptive sampling is on, the statistical error halt stops at 3% noise, and OIDN runs at the end. For a viewport preview, use the camera view in Rendered shading — the interactive OIDN tick cleans the image roughly once per second.

3. Optional: import Cycles settings

Opening a .blend authored for Cycles? Run Render Properties → Render Settings Helper for guided configuration, or click Import Cycles Settings to copy scene.cycles samples, bounce depths, and the denoise flag in one shot.

Sensible defaults

PropertyDefaultWhy
halt.use_noise_levelon, 3% Rendering stops itself when the target error is reached.
sampler.typeSOBOL Per-pixel adaptive thresholds memoized across passes.
denoiser.enabledon OIDN 2.x on Metal GPU (~17× faster than CPU OIDN).
path.hybridbackforward_enableon Adds GPU light tracing — caustics converge without extra setup.
