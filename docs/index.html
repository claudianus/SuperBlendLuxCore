SuperLuxCore is a production path tracer with unbiased, biased and realtime modes — GPU light tracing for caustics, statistical adaptive-error halting, OIDN denoising, and full Cycles .blend compatibility.

Three engines, one quality bar

ModeEngineUse it for
UnbiasedPATH / BIDIR Reference-grade physical accuracy; ground-truth validation.
Biased (production)PATH + adaptive error Fire-and-forget convergence: statistical noise-level halt, adaptive sampling, OIDN. The default workhorse.
RealtimeRTPATHOCL Viewport lookdev + fast animation previews at reduced resolution.

GPU light tracing

Caustics via a dedicated light-path subpass with focus-guided emission, MGE, and LMNEE — renders SDS chains that pure path tracing cannot reach.

Adaptive error halt

Statistical per-pixel relative-error target with a Corona-style "noise level" stop. Rendering finishes itself; no sample-count guessing.

OIDN denoising

Intel Open Image Denoise on Metal GPU — component-decomposed mode for clean AOVs, ~17× faster than CPU OIDN.

Cycles .blend import

Principled BSDF, textures and scene settings map 1:1 onto SuperLuxCore materials. One-click Import Cycles Settings for samples/bounces/denoise.

OpenPBR Surface

Principled maps onto the OpenPBR lobe natively: SSS radius/scale/IOR/anisotropy, coat, fuzz, thin film.

Metal HWRT

Apple-silicon ray tracing with MTLAccelerationStructure — triangle + curve primitives, instancing, motion blur.

Quickstart

1. Install the release ZIP via Edit → Preferences → Add-ons → Install from Disk.
2. Switch Render Engine to SuperLuxCore.
3. Press F12. The adaptive-error halt stops the render when the target noise level is reached — nothing else to set.
