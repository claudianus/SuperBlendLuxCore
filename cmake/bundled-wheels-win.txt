# Blender's extension installer does NOT resolve wheel dependencies, so the
# pysuperluxcore `Requires-Dist: nvidia-cuda-nvrtc-cu12 == 12.8.93` must be
# bundled explicitly - without it cuew cannot load NVRTC and the CUDA/OptiX
# backend is silently disabled (only OpenCL remains on NVIDIA GPUs).
# 12.8+ is required for Blackwell (sm_120, e.g. RTX 50xx).
#
# Hashes: https://pypi.org/pypi/nvidia-cuda-nvrtc-cu12/12.8.93/json
